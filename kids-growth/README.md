# 小朋友成长系统

家庭自用的小朋友成长记录与习惯养成系统，覆盖 3 岁幼儿园小班 → 18 岁。本地优先、离线可用、无需账号登录，数据只存在本机浏览器中。在「成长记录」之上，还内建一个**学科无关的学习引擎**（间隔重复 SRS + 配置化练习模式），接入英语 / 语文 / 数学 / 全学科错题本。

> 📱 **在线体验（手机可打开、可添加到主屏幕）**：https://zhaolinzhou7-ops.github.io/production-project/
>
> 详细需求见 [`docs/SPEC.md`](docs/SPEC.md) 与种子数据 [`docs/SEED.md`](docs/SEED.md)；产品长期规划见 [`docs/PRODUCT_OS_PLAN.md`](docs/PRODUCT_OS_PLAN.md)。

## 技术栈

- React 19 + Vite + TypeScript + Tailwind CSS v4
- Zustand（应用状态：当前孩子、家长/孩子模式）
- Dexie.js（IndexedDB 本地数据库）
- react-router-dom（路由）
- lucide-react（图标）
- vite-plugin-pwa（离线可用、可添加到主屏幕）

## 阶段 0 说明

- 默认家长 PIN 为 `1234`，可在「家长设置」中修改。
- 首次打开会引导添加第一个孩子的档案；添加后可在「家长模式 → 管理孩子」中新增、编辑或删除。
- 「家长模式 → 家长设置」中可一键导出全部数据为 JSON 备份，也可导入备份文件（导入会覆盖当前数据，操作前会二次确认）。
- 数据全部保存在浏览器 IndexedDB 中，刷新或重新打开不会丢失；照片以压缩后的 base64 存储，随备份一起导出。

## 阶段 1 说明

- 「家长模式 → 任务与积分管理」可新增/编辑/删除任务（分类、每日/每周指定日/一次性、积分、启用状态），也可一键导入 13 个默认任务模板。
- 孩子端首页展示当日应完成的任务（按类型自动筛选：每日任务每天都在、每周任务只在指定星期几出现、一次性任务完成一次后不再出现），点一下即打卡，有飘分动画即时反馈。
- 积分分为「可用余额」（完成任务加、后续兑换会减）与「累计 XP」（只增不减，决定等级），等级阶梯与进度条实时展示；升级时有全屏彩带庆祝动画。
- 「打卡补登 / 撤销」面板支持家长为任意日期补登或撤销某个任务的打卡（孩子端本身不能撤销，防止刷分）。

## 阶段 2 说明

- 「家长模式 → 奖励与兑换管理」可新增/编辑/删除奖励（图标、所需积分、可选库存、启用状态），也可一键导入 10 个默认奖励模板。
- 孩子端「奖励商城」可查看可兑换奖励并申请兑换；余额不足或库存已兑完时按钮会禁用并给出提示；兑换后进入「待审批」状态，孩子无法自行扣分兑换。
- 家长在「奖励与兑换管理」中审批兑换申请：通过则扣减积分余额、按需减少库存并记录兑换流水；拒绝则不影响积分。
- 连续打卡天数（streak）会在孩子端首页展示；14 个成就徽章按规则自动解锁（首次打卡/兑换、连续打卡、分类累计、达到指定等级等），解锁时有庆祝动画，「徽章墙」页面可查看全部徽章的解锁状态。

## 阶段 3 说明

- 「家长模式 → 身体发育记录」可录入身高/体重/头围记录（日期可回填）、查看生长曲线图，以及记录成长里程碑（预设类型 + 自定义 + 照片）。
- **生长曲线百分位数据**内置于 `src/data/growthStandards.json`，由 WHO 官方 L/M/S 参数表（世界卫生组织儿童生长标准 0–60 月龄 + WHO 2007 年生长参考标准 61–228 月龄，取自 WHO 官方 GitHub 仓库 [`WorldHealthOrganization/anthro`](https://github.com/WorldHealthOrganization/anthro) 与其衍生的 CRAN `childsds` 包）按标准 LMS 公式计算得出 P3/P10/P25/P50/P75/P90/P97，分性别、真实数值，未编造。身高标准覆盖 0–19 岁，体重标准覆盖 0–10 岁（WHO 官方仅发布到 10 岁，10 岁以上因肥胖流行病学原因不再提供体重百分位参考，界面会如实说明而非编造数据）。
- BMI 自动计算，并按 WHO 官方 BMI-for-age 分类阈值（z 分数 <-2 偏瘦，-2~+1 正常，+1~+2 偏重，>+2 肥胖）给出参考分类，同时显示"超过同龄同性别约 X% 的孩子"，页面明确标注"仅供参考，非医疗诊断，如有异常请咨询医生"及数据来源。

## 阶段 4 说明

- 「家长模式 → 学习成长档案」分两个页签：**作品集**（类型：画作/手工/作业/证书/奖状/照片/其他，标题、描述、多张照片、标签，网格画廊展示，点击照片全屏查看、可左右翻页）和**家长寄语**（日期、标题、正文、照片、五种心情标签）。
- **成长时间线**自动聚合五类事件：里程碑、作品入档、家长寄语、升级事件（由积分流水按等级阶梯推导，无需单独存储）、徽章解锁，按时间倒序展示为竖向故事流。孩子端首页新增「时间线」入口，孩子也能翻看自己的成长故事。
- 首件作品入档会自动触发「小小艺术家」徽章解锁。

## 阶段 5 说明

- **家长中心即综合仪表盘**：顶部依次展示（按需出现）备份提醒条、「快速上手」引导清单（导入任务 → 设置奖励 → 记录身高体重，完成项自动打勾消失）、等级与 XP 进度、积分余额 / 连续打卡 / 本周完成率三格统计、最新身高体重 + 迷你趋势线、最近三条成长动态，下方是各管理模块入口。
- **本周完成率**按最近 7 天内每天实际应做的任务数（每日任务 + 当天命中的每周任务）与实际完成数计算。
- **备份提醒**：有数据但从未备份、或距上次备份超过 30 天时，仪表盘顶部出现提醒，点击直达备份页。
- 庆祝动画（升级/徽章 confetti）、PWA（离线可用、可添加到主屏幕）、空状态引导已在前几阶段落地。

- **批次 2 · 健康扩展**：牙齿（长牙/换牙/龋齿/正畸等 + 牙位 + 照片）、就医（症状/诊断/用药/医院 + **新发现过敏醒目标记**）、体检（机构/结论/复查项 + 报告照片）、疫苗接种（14 种常见疫苗 + 剂次 + 接种单位）四个模块全部通过通用记录引擎的**纯配置**实现，未新增任何页面代码；「健康档案」入口现聚合五个模块并显示各自最近一条记录。
- **批次 3 · 兴趣与情绪**：兴趣特长管理（项目/类别/开始时间/进行中状态）+ 考级记录（项目/级别/结果/机构 + 证书照片）与比赛获奖（比赛/奖项/校级—国际级 + 照片），考级获奖并入成长时间线；情绪记录模块（七种情绪 + 强度 1–5 + 触发事件）；**青春期关怀**：初/高中孩子近 14 天负面情绪记录（含家长日记心情）≥3 次时，仪表盘出现温和提示——明确标注「仅基于记录条数，非心理评估，持续低落请寻求专业帮助」。
- **批次 4 · 阅读与年度报告**：阅读记录模块（书名/作者/1–5 星喜欢程度/一句话感想）；**年度成长报告**页按年份聚合全部数据——今年长高多少、体重变化、读完几本书、完成打卡与获得成长值、解锁徽章、记录考试与各科平均得分率、里程碑清单、闪光时刻精选、最喜欢的书，多年份可切换，一键回顾「孩子的这一年」。

- **真人发音**：单词用有道 `dictvoice` 真人音源，用 `<audio>` 直接播放 URL（绕开跨域、并在用户点击的同一手势内同步 `play()`，满足移动端发声要求）；取不到/离线时回退系统 TTS（`src/lib/audio.ts`）。跟读用浏览器语音识别做对/错比对，不支持时优雅降级为自评。
- **与游戏化打通**：学习会话答对即加积分（走 `pointLedger`）、联动等级/庆祝动画/成就（新增「开卷有益/词汇小达人/词汇高手/学习之星」等），分龄 tone 决定童趣/克制。孩子端首页与家长仪表盘均有「学习中心」入口。

### 学习引擎（批次 1 · 英语完整）

- **听写**：新增第 5 种单词练法「听写」——只放真人发音、盲写单词，与「拼写」（看中文写词）互补；进入即自动播报，写完对照答案与音标。
- **错词本（自动收录）**：任意词库里答错的单词自动进入该孩子的「错词本」卡组（按词去重、已掌握不再收），错词本本身按 SRS 复习、支持全部单词练法与真人发音，练熟即自动沉降。
- **自定义词本**：家长可粘贴自己的词表创建词本，`parseWordList` 智能解析「word 释义 / word,释义 / word /音标/ 释义」多种格式，实时显示已识别词数。
- **初中/高中词库激活**：家长可在「学习管理」里把小初高任意分级词库分配给孩子（学段默认词库仍会自动分配），互不冲突、幂等。
- **家长学习管理页**（`/parent/learn`，`ParentLearningPage`）：今日学习进度 + 可设**每日目标**（存于 `settings.learnGoals`，随备份保存）；掌握/学习中/未学/今日待学/连续天数/总词卡概览；**近 14 天练习量**柱状图（学习曲线）；**薄弱词**（易忘、未掌握，按遗忘次数排序）；词库管理（分配分级库、建/删自定义词本、查看各库掌握量）。家长仪表盘「学习管理」入口指向此页。
- 数据层无新增表——错词本/自定义词本复用 v3 的 `decks/cards/studyStates`，随现有备份完整往返。全流程经无头浏览器实测：听写、答错入错词本、家长页统计/曲线/薄弱词/自定义词本解析/每日目标，零 console 报错。

### 学习引擎（批次 2 · 语文：古诗 + 识字）

- **学科无关引擎验证**：不写新页面，仅加**内容包 + 练习模式配置**即接入两门新内容——同一套 SRS/会话/积分/家长统计直接复用。
- **小学·唐诗启蒙**（`poems-primary.json`，103 首）：源自开源 **chinese-poetry 唐诗三百首**中的**绝句**，用 **OpenCC 繁简表**转为简体、按结构（四句五/七言）筛选，含标题/作者/朝代/逐句。两种练法:**朗读背诵**（中文 TTS 逐首朗读 + 会背/还不熟自评）、**补全诗句**（随机挖去一句，从同字数、非本诗的诗句里 4 选 1）。
- **小学·常用识字**（`hanzi-primary.json`，500 字）：字形+拼音取自开源 **makemeahanzi**，字频与**组词**取自开源 **rime-essay** 词频（为每个字选最高频的二字词作组词），全部简体。两种练法:**认字**（看字→读音+组词，中文 TTS）、**听音选字**（听读音，从 4 个汉字里选）。
- **中文发音**：古诗/识字统一走系统 `speechSynthesis` 中文 TTS（`zh-CN`，古诗放慢语速），与英语的真人音源分流；`playAudio` 按学科自动选择音源。
- 小学学段进入学习中心会自动分配「基础高频词 + 唐诗启蒙 + 常用识字」；家长可在「学习管理」按需增删。数据仍复用 v3 三表、无迁移，备份照常往返。全流程无头浏览器实测（认字/听音选字/朗读背诵/补全诗句）零 console 报错。

### 学习引擎（批次 3 · 数学：口算/速算）

- **随机生成、无需数据**：`src/lib/mathDrill.ts` 按学段随机出题——加法/减法（幼儿 10 以内、小学 100 以内、更大 1000 以内）、乘法口诀（九九表）、乘法（含两位数×一位数）、除法（**整除倒推、无余数**）、混合（四则随机）。减法保证不为负。
- **限时闯关**（`MathDrillPage`，`/learn/math`）：选题型 + 题量（10/20/30）→ 逐题作答、即时对错（答错显示正确答案）、顶部计时器 → 结算展示**正确率 / 用时（含每题均时）/ 积分**，联动升级/成就/彩带（分龄 tone）。孩子端学习中心新增「口算练习」入口卡。
- **接入统计**：结果写入 v3 已有的 `drillResults` 表（`finishDrill`），答对即加分（走 `pointLedger`）；家长「学习管理」的**近 14 天练习量**与**连续学习天数**已把口算题数并入，语文/英语/数学练习统一计。
- 无新增表、无迁移；`tsc`+`oxlint`+`build` 全绿；无头浏览器实测（乘法口诀全对→结算加分、混合题覆盖 +−×÷、答错显示正确答案）零 console 报错。

### 学习引擎（批次 4 · 全学科错题本 + 学习数据汇总）

- **全学科错题本**（`ErrorBookPage`，`/learn/errorbook`）：孩子/家长把各科做错的题**拍照或打字**记进来（题干/答案/学科可选），走引擎的 `review` 模式**看题回想 → 翻答案自评（已掌握/还没掌握）**，按 SRS 排期重做——答对拉长间隔、答错很快再现，直到真正掌握。学习中心新增「错题本」入口；错题本卡组独立管理，不混入通用词库列表。英语错词本(批次1)与手动错题本用 `itemType`（`word` vs `wrong`）区分，各自独立。
- **年度成长报告纳入学习**（`annualReport.ts` + `ParentReportPage`）：新增「今年的学习」板块——年内**掌握单词 / 掌握汉字 / 背会古诗 / 口算题数 / 口算正确率 / 学习天数**；只有学习数据的孩子也能生成报告（年份集合并入 `studySessions`/`drillResults`）。
- **成长时间线纳入学习**（`timeline.ts`）：**背会的古诗逐首**上时间线（《静夜思》…），**词汇/汉字掌握量**按 10/50/100/200/500/1000 阈值生成里程碑，按掌握时间(SRS `lastReviewed`)排入故事流。

### 学习趣味包（让练习"像游戏"）
