# 小朋友成长系统

家庭自用的小朋友成长记录与习惯养成系统。本地优先、离线可用、无需账号登录，数据只存在本机浏览器中。

> 详细需求见 [`docs/SPEC.md`](docs/SPEC.md) 与种子数据 [`docs/SEED.md`](docs/SEED.md)。

## 技术栈

- React 19 + Vite + TypeScript + Tailwind CSS v4
- Zustand（应用状态：当前孩子、家长/孩子模式）
- Dexie.js（IndexedDB 本地数据库）
- react-router-dom（路由）
- lucide-react（图标）
- vite-plugin-pwa（离线可用、可添加到主屏幕）

## 开发

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 生产构建
```

## 阶段 0 说明

- 默认家长 PIN 为 `1234`，可在「家长设置」中修改。
- 首次打开会引导添加第一个孩子的档案；添加后可在「家长模式 → 管理孩子」中新增、编辑或删除。
- 「家长模式 → 家长设置」中可一键导出全部数据为 JSON 备份，也可导入备份文件（导入会覆盖当前数据，操作前会二次确认）。
- 数据全部保存在浏览器 IndexedDB 中，刷新或重新打开不会丢失；照片以压缩后的 base64 存储，随备份一起导出。

## 阶段 1 说明

- 「家长模式 → 任务与积分管理」可新增/编辑/删除任务（分类、每日/每周指定日/一次性、积分、启用状态），也可一键导入 13 个默认任务模板。
- 孩子端首页展示当日应完成的任务（按类型自动筛选：每日任务每天都在、每周任务只在指定星期几出现、一次性任务完成一次后不再出现），点一下即打卡，有飘分动画即时反馈。
- 积分分为「可用余额」（完成任务加、后续兑换会减）与「累计 XP」（只增不减，决定等级），等级阶梯与进度条实时展示；升级时有全屏彩带庆祝动画。
- 「打卡补登 / 撤销」面板支持家长为任意日期补登或撤销某个任务的打卡（孩子端本身不能撤销，防止刷分）。

## 阶段 2 说明

- 「家长模式 → 奖励与兑换管理」可新增/编辑/删除奖励（图标、所需积分、可选库存、启用状态），也可一键导入 10 个默认奖励模板。
- 孩子端「奖励商城」可查看可兑换奖励并申请兑换；余额不足或库存已兑完时按钮会禁用并给出提示；兑换后进入「待审批」状态，孩子无法自行扣分兑换。
- 家长在「奖励与兑换管理」中审批兑换申请：通过则扣减积分余额、按需减少库存并记录兑换流水；拒绝则不影响积分。
- 连续打卡天数（streak）会在孩子端首页展示；14 个成就徽章按规则自动解锁（首次打卡/兑换、连续打卡、分类累计、达到指定等级等），解锁时有庆祝动画，「徽章墙」页面可查看全部徽章的解锁状态。

## 阶段 3 说明

- 「家长模式 → 身体发育记录」可录入身高/体重/头围记录（日期可回填）、查看生长曲线图，以及记录成长里程碑（预设类型 + 自定义 + 照片）。
- **生长曲线百分位数据**内置于 `src/data/growthStandards.json`，由 WHO 官方 L/M/S 参数表（世界卫生组织儿童生长标准 0–60 月龄 + WHO 2007 年生长参考标准 61–228 月龄，取自 WHO 官方 GitHub 仓库 [`WorldHealthOrganization/anthro`](https://github.com/WorldHealthOrganization/anthro) 与其衍生的 CRAN `childsds` 包）按标准 LMS 公式计算得出 P3/P10/P25/P50/P75/P90/P97，分性别、真实数值，未编造。身高标准覆盖 0–19 岁，体重标准覆盖 0–10 岁（WHO 官方仅发布到 10 岁，10 岁以上因肥胖流行病学原因不再提供体重百分位参考，界面会如实说明而非编造数据）。
- BMI 自动计算，并按 WHO 官方 BMI-for-age 分类阈值（z 分数 <-2 偏瘦，-2~+1 正常，+1~+2 偏重，>+2 肥胖）给出参考分类，同时显示"超过同龄同性别约 X% 的孩子"，页面明确标注"仅供参考，非医疗诊断，如有异常请咨询医生"及数据来源。

## 阶段 4 说明

- 「家长模式 → 学习成长档案」分两个页签：**作品集**（类型：画作/手工/作业/证书/奖状/照片/其他，标题、描述、多张照片、标签，网格画廊展示，点击照片全屏查看、可左右翻页）和**家长寄语**（日期、标题、正文、照片、五种心情标签）。
- **成长时间线**自动聚合五类事件：里程碑、作品入档、家长寄语、升级事件（由积分流水按等级阶梯推导，无需单独存储）、徽章解锁，按时间倒序展示为竖向故事流。孩子端首页新增「时间线」入口，孩子也能翻看自己的成长故事。
- 首件作品入档会自动触发「小小艺术家」徽章解锁。

## 阶段 5 说明

- **家长中心即综合仪表盘**：顶部依次展示（按需出现）备份提醒条、「快速上手」引导清单（导入任务 → 设置奖励 → 记录身高体重，完成项自动打勾消失）、等级与 XP 进度、积分余额 / 连续打卡 / 本周完成率三格统计、最新身高体重 + 迷你趋势线、最近三条成长动态，下方是各管理模块入口。
- **本周完成率**按最近 7 天内每天实际应做的任务数（每日任务 + 当天命中的每周任务）与实际完成数计算。
- **备份提醒**：有数据但从未备份、或距上次备份超过 30 天时，仪表盘顶部出现提醒，点击直达备份页。
- 庆祝动画（升级/徽章 confetti）、PWA（离线可用、可添加到主屏幕）、空状态引导已在前几阶段落地。
