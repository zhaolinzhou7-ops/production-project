## 1. 产品概述

一个给家庭使用的、记录并激励孩子成长的综合应用。三大支柱合一：

- **支柱 A · 习惯养成 + 积分奖励（游戏化）**：把日常好习惯做成任务，打卡得积分、升等级、解锁成就、兑换家长设定的真实奖励。
- **支柱 B · 身体发育记录**：记身高体重，叠加标准生长曲线看百分位，标记成长里程碑。
- **支柱 C · 学习成长档案**：作品集、奖状、成长时间线、家长寄语，承载情感价值。

**双模式**：孩子端（简单、好玩、即时反馈）+ 家长端（管理、录入、看数据，PIN 保护）。支持**多个孩子**。

---

## 2. 目标用户与场景

- **主用户**：家长（手机为主）+ 孩子（手机/平板）。
- **典型场景**：
  - 早上孩子自己打开看"今天要做什么"，完成一项点一下，看到积分和进度条涨、有庆祝动画。
  - 晚上家长录入今日身高体重/补登任务/审批孩子的奖励兑换申请。
  - 周末家长上传孩子的画作、奖状，写一句寄语，时间线上多一条记录。
  - 家长在仪表盘看到本周完成率、积分趋势、生长曲线一眼掌握。

## 3. 核心模块与功能

### 3.1 支柱 A — 习惯养成 + 积分奖励

**任务/习惯**
- 家长创建任务：标题、图标、分类（学习/生活/运动/品德/家务/其他）、类型（每日 / 每周指定日 / 一次性）、积分值、生效状态。
- 任务列表按分类分组；可启用/停用、编辑、删除。

**打卡**
- 孩子端"今日任务"卡片：点一下完成 → 即时反馈（动画 + 积分飘出）。
- 支持补登/撤销（家长端）；每日同一任务只计一次。
- 连续打卡 streak 统计。

**积分与等级（两套数值，务必区分）**
- **可用积分余额**：完成任务 +、兑换奖励 −。用于兑换。
- **累计经验 XP**：只增不减（= 历史累计获得的积分），决定**等级**。这样兑换奖励不会掉级。
- 等级阶梯（可在设置里调，示例）：
  | 等级 | 称号 | 累计 XP |
  |---|---|---|
  | Lv1 | 🌱 萌芽 | 0 |
  | Lv2 | 🌿 嫩苗 | 100 |
  | Lv3 | 🌳 小树 | 250 |
  | Lv4 | 💪 茁壮 | 500 |
  | Lv5 | 🍃 繁叶 | 900 |
  | Lv6 | 🌸 开花 | 1500 |
  | Lv7 | 🍎 结果 | 2200 |
  | Lv8 | 🌲 大树 | 3000 |
  | Lv9 | ✨ 森林之星 | 4000 |
  | Lv10 | ⭐ 成长大师 | 5200 |
- 升级时全屏庆祝动画。

**成就 / 徽章**
- 规则触发自动解锁，徽章墙展示。示例：
  - 坚持之星（连续打卡 7 天）
  - 完美一天（某日今日任务全部完成）
  - 全勤一周（一周每天都有完成）
  - 百题达成（累计完成 50 / 100 个任务）
  - 第一次兑换 / 第一次记录身高 / 第一件作品入档

**奖励商城**
- 家长定义"真实奖励"商品：名称、图标、所需积分、库存（可选）。示例：看 30 分钟动画片(50)、周末去公园(200)、选一本新书(150)、一次冰淇淋(80)、决定周末晚餐(120)、多玩 20 分钟(60)。
- 孩子端可"申请兑换" → 进入**待家长审批**；审批通过后扣积分、记录兑换流水。
- 孩子**不能**自助直接扣分兑换（防刷分）。

**默认任务模板（首次使用一键导入，让产品开箱可用）**
> 早睡早起 · 自己刷牙 · 整理房间 · 阅读 20 分钟 · 完成作业 · 帮忙做家务 · 运动 30 分钟 · 练琴 · 好好吃饭不挑食 · 礼貌待人（分类/积分给合理默认值，家长可改）

### 3.2 支柱 B — 身体发育记录

- **身高体重记录**：日期、身高(cm)、体重(kg)、头围(可选，小龄)、备注。按时间倒序列表 + 可编辑。
- **生长曲线**：把孩子的记录点叠加在**标准百分位带**(P3/P10/P25/P50/P75/P90/P97)上，分性别。
  - **数据要求**：内置 WHO（0–5 岁）或中国卫健委《7 岁以下儿童生长标准》/《0–18 岁儿童青少年身高体重百分位》的真实数值，作为静态资源。**禁止编造**，并在页面标注数据来源。
- **BMI**：自动计算并给出"偏瘦/正常/偏胖"参考（基于年龄性别 BMI 百分位）。页面明确标注：**仅供参考，非医疗诊断，异常请咨询医生**。
- **里程碑**：日期 + 类型（预设：第一次走路 / 第一颗牙 / 第一次骑车 / 第一天上学… + 自定义）+ 文字 + 照片。

### 3.3 支柱 C — 学习成长档案

- **作品集**：日期、类型（画作/手工/作业/证书/奖状/照片）、标题、描述、多张照片、标签。网格画廊展示，可点开大图。
- **成长时间线**：自动聚合里程碑 + 作品 + 升级事件 + 家长寄语，按时间倒序的"故事流"。
- **家长寄语 / 成长日记**：日期、标题、正文、照片、心情标签。

### 3.4 通用能力

- **多孩支持**：每个孩子独立档案，顶部可切换当前孩子。多孩之间**不做直接排行榜对比**（避免攀比）。
- **双模式切换**：
  - 孩子端：默认进入，只读 + 打卡 + 申请兑换，界面简单好玩。
  - 家长端：**PIN 码进入**，可管理一切（任务、积分、奖励审批、录入发育数据、上传作品、写寄语、看仪表盘）。
- **综合仪表盘**（家长端首页/概览）：当前等级与进度条、积分余额、连续打卡天数、本周完成率、最新身高体重 + 迷你曲线、最近时间线。
- **数据备份**：一键导出全部数据为 JSON；可导入恢复。照片一并处理（base64/blob）。
- **设置**：等级阶梯、PIN、主题、是否开启"扣分/挑战"机制（默认关闭）、数据备份提醒。

## 4. 数据模型（实体与关键字段）

```
Child         { id, name, nickname?, gender, birthdate, avatar?, createdAt }
Task          { id, childId, title, icon, category, type(daily|weekly|once),
                weeklyDays?[], points, active, createdAt }
CheckIn       { id, taskId, childId, date, status(done|undo), pointsAwarded, note?, createdAt }
PointLedger   { id, childId, delta, reason, refType(checkin|redeem|achievement|manual),
                refId?, balanceAfter, timestamp }   // 决定"可用积分余额"
//  累计经验 XP = 所有 delta>0 之和（或单独维护一个 xpTotal 只增字段）
LevelConfig   { level, title, requiredXP }           // 可配置，存设置里
Achievement   { id, code, name, desc, icon, rule }   // 规则定义
Unlock        { id, childId, achievementCode, unlockedAt }
Reward        { id, childId?, name, icon, costPoints, stock?, active }  // childId 空=共享
Redemption    { id, childId, rewardId, costPoints, status(pending|approved|rejected|fulfilled),
                requestedAt, decidedAt? }
GrowthRecord  { id, childId, date, heightCm?, weightKg?, headCm?, note? }  // BMI/百分位计算得出
Milestone     { id, childId, date, type, title, note?, photo? }
Portfolio     { id, childId, date, type, title, desc?, photos[], tags[] }
DiaryEntry    { id, childId, date, title?, content, photos[], mood? }
Settings      { parentPin, theme, enablePenalty(false), levelLadder, ... }
```

**百分位/BMI 为计算字段**，不入库，按标准表实时算。

## 5. 技术选型（Claude Code 自定，含建议）

**推荐默认 · 本地优先纯前端（无服务器、数据在本机、最省事、最隐私）**
- React 18 + Vite + TypeScript + Tailwind CSS
- 状态：Zustand（或 Context）
- 本地数据库：**Dexie.js（IndexedDB）**，存结构化数据 + 照片 blob
- 图表：Recharts（生长曲线、积分趋势、完成率）
- 图标：lucide-react；动画：framer-motion + canvas-confetti（庆祝）
- PWA：vite-plugin-pwa（可"添加到主屏幕"，离线可用）
- 备份：导出/导入 JSON

**可选 · 需多设备同步时（家长手机 + 平板共享一份数据）**
- 增加轻量后端：FastAPI(Python) 或 Express(Node) + SQLite，前端改为请求 API。
- 仅当确有多设备需求才上；否则别引入后端。

> 约束：离线可用、数据持久不丢、可导出备份、移动端优先、全中文。Claude Code 可在此范围内替换等价库。

## 6. UI / UX 方向

- **移动端优先 + 响应式**；大点击区域；暖色、圆角、友好。
- **孩子端**：吉祥物/头像、今日任务卡片一点即完成、醒目的积分与等级进度条、徽章墙；完成与升级有 confetti 庆祝；尽量少字、多图标。
- **家长端**：清爽的管理界面，列表 + 表单 + 图表；进入需 PIN。
- **仪表盘**：卡片式概览，一屏看懂一个孩子的状态。
- **空状态引导**：第一次进来引导"添加孩子 → 一键导入默认任务 → 设置奖励"。
- 视觉细节交给 Claude Code 自身的 frontend-design 规范处理，保持有设计感、不要模板感。

---

## 7. 面向儿童的健康设计原则（必须遵守）

- **正向激励为主**，扣分/惩罚机制默认关闭、可选开启。
- 奖励**由家长定义并审批**，孩子不能自助刷分兑换。
- 家长端 **PIN 保护**，孩子改不了规则和积分。
- 多孩之间**不做排行榜式直接攀比**。
- **防沉迷**：不设"无限刷分"机制；庆祝动画适度，不喧宾夺主。
- **隐私**：数据与照片默认只存本机，不上传云端（除非家长主动导出备份）。
- 发育数据明确标注"仅供参考、非医疗诊断"。
- 价值导向：时间线/作品/寄语承载情感，提醒家长别只盯积分。

## 8. 实施阶段（逐阶段交付，每阶段都要能跑）

- **阶段 0 · 地基**：脚手架 + 数据层(Dexie) + 多孩 CRUD + 双模式切换 + PIN + 导出/导入 JSON。
- **阶段 1 · 习惯与积分核心**：任务 CRUD、每日打卡、积分流水、累计 XP 与等级/进度、孩子端"今日任务"、家长端任务管理、默认任务模板一键导入。
- **阶段 2 · 奖励与成就**：奖励商城、兑换申请 → 家长审批 → 扣分、连续打卡、成就/徽章解锁与徽章墙。
- **阶段 3 · 身体发育**：身高体重记录、内置标准百分位、生长曲线、BMI 参考、里程碑。
- **阶段 4 · 成长档案**：作品集、奖状、成长时间线（聚合）、家长寄语/日记。
- **阶段 5 · 仪表盘与打磨**：综合仪表盘、庆祝动画、PWA、空状态引导、备份提醒、细节体验打磨。

> 每个阶段结束：能演示 + git commit + 简短自测。

## 9. 非功能性需求

- 本地优先、离线可用、**数据持久不丢**（每次写入即落盘 IndexedDB）。
- 移动端优先 + 响应式。
- 全中文界面。
- 无需登录/账号；家长端 PIN。
- 照片本地存储，注意体积（可压缩后存）。
- TypeScript 类型完整、模块清晰、易维护。
- 性能流畅，列表/图表不卡。
