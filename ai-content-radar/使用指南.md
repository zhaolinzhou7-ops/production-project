# 📖 使用指南（保姆级 · 完全不懂技术也能用）

> 这个项目能做什么？
> 自动分析全网短视频 → 告诉你「现在做什么内容能火」→ 再自动帮你写出
> 选题、小说、短剧分镜、AI 视频提示词，并给内容打分（能不能火）。
>
> 下面从**最简单**到**最完整**给你三条路，按你的情况挑一条即可。

---

## 🌟 方案一：只想「看结果」——最简单，推荐先做这个

**你会得到什么**：一个像网页一样的漂亮报告，打开就能看到十大模块的全部分析结果。
**需要装东西吗**：不需要。**需要联网/密钥吗**：不需要。

### 操作步骤（3 步）

1. **下载报告文件**
   - 打开这个网址（就是你的项目仓库）：
     `https://github.com/zhaolinzhou7-ops/production-project`
   - 进入文件夹：`ai-content-radar` → 找到 **`报告.html`**
   - 点开它，页面右上角有个下载按钮（↓ 图标 / "Download raw file"），点一下保存到电脑。

2. **打开报告**
   - 到你电脑的「下载」文件夹，找到 **`报告.html`**。
   - **双击它**（会自动用浏览器 Chrome/Edge/Safari 打开）。

3. **看结果** ✅
   - 从上到下依次是：爆款规律、红海赛道、用户情绪、蓝海机会、
     100 个选题、小说、分镜、视频提示词、能不能火的评分。

> 📌 报告里的数据是「演示样例」。想换成你自己关心的题材，做方案二。

## 🛠 方案二：想「换成自己的题材、重新生成报告」

需要装一个免费软件 **Python**（一次性，约 5 分钟）。

### 第 1 步：装 Python
- **Windows**：打开微软应用商店(Microsoft Store)，搜索 **Python 3.12**，点「获取/安装」。
  （或到 https://www.python.org 点黄色大按钮 Download，安装时**务必勾选**
  「Add Python to PATH」再点 Install。）
- **Mac**：到 https://www.python.org 下载 macOS 版，一路「继续」装完。

### 第 2 步：下载整个项目
- 打开 `https://github.com/zhaolinzhou7-ops/production-project`
- 点绿色 **`< > Code`** 按钮 → **Download ZIP** → 解压到桌面。

### 第 3 步：一键生成报告（不用敲命令）
进入解压出来的文件夹 `ai-content-radar`，然后：
- **Windows**：双击 **`一键生成报告.bat`**
- **Mac**：双击 **`一键生成报告.command`**
  （若提示"无法打开"，右键点它 → 打开 → 再点"打开"即可。）

跑完会在同目录生成新的 **`报告.html`**，双击查看。

### 第 4 步（可选）：换成你的题材
用「记事本 / 文本编辑」打开 `生成报告.py`，找到最上面的
`build_sample()` 里的 `tracks = [...]`，把里面的标题和关键词改成你的赛道，
保存后再双击一次「一键生成报告」即可。

## 🚀 方案三：想要「完整的网站系统」（带后台+页面）

这是给未来正式运营用的，需要装 **Docker Desktop**（免费）。
如果你只是想看效果，方案一/二就够了，这步可以先跳过。

### 第 1 步：装 Docker Desktop
- 到 https://www.docker.com/products/docker-desktop 下载安装，装完打开它
  （等左下角变绿色/显示 running）。

### 第 2 步：一键启动
进入 `ai-content-radar` 文件夹：
- **Windows**：双击 **`一键启动网站.bat`**
- **Mac**：双击 **`一键启动网站.command`**

第一次会自动下载并构建，耐心等几分钟。看到 `Started` 字样后：
- 打开浏览器访问 **http://localhost:3000** → 控制台页面
- 点页面上的「▶ 运行闭环」按钮，就能在线跑一遍。
- 后台接口文档在 **http://localhost:8000/docs**

### 第 3 步：关闭
在弹出的黑色窗口里按 `Ctrl + C`，或直接关掉 Docker Desktop。

## 🤖 想让 AI 写得更好？（接入真实大模型，选做）

不接也能用（系统用内置的演示算法兜底）。想让小说/分镜更精彩，可接入真实 AI：

1. 准备一个 API Key（OpenAI / Claude / Gemini 任选其一，需自行申请）。
2. 在 `ai-content-radar/infra` 文件夹里新建一个文本文件叫 `.env`，写入：
   ```
   DEFAULT_LLM_PROVIDER=openai
   OPENAI_API_KEY=你的密钥粘贴到这里
   ```
   （用 Claude 就写 `anthropic` + `ANTHROPIC_API_KEY`；用 Gemini 就写 `gemini` + `GEMINI_API_KEY`）
3. 重新双击「一键启动网站」即可，**代码一行都不用改**。

## ❓ 常见问题

| 问题 | 怎么办 |
|------|--------|
| 双击 .bat/.command 一闪而过 | 说明没装好 Python，回到方案二第 1 步重装并勾选 PATH |
| Mac 提示"未受信任/无法打开" | 右键点该文件 → 选「打开」→ 再点「打开」 |
| 报告打开是乱码 | 用 Chrome 或 Edge 打开（不要用很老的 IE） |
| 想看每个模块什么意思 | 看 `docs/` 文件夹里的 8 份说明文档 |
| 想验证程序没问题 | 会敲命令的话：在 `ai-content-radar` 目录运行 `python3 -m unittest discover tests` |
